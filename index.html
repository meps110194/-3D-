📐 雙人 3D 足球靜態 P2P 網頁架構規劃

1. 無伺服器 IP 直連架構 (Serverless WebRTC IP P2P)

純靜態 HTML 網頁不依賴任何後端 WebSocket 伺服器。透過瀏覽器內建的 RTCPeerConnection 與 Google STUN 節點進行 ICE 候選位址蒐集，自動擷取裝置的區域網路 IP (LAN Host IP) 與 公網 NAT 映射 IP (Reflexive IP)，壓縮編碼為交換權杖，完成後即建立低延遲 UDP 點對點通道。

2. 物理權威同步與預測插值 (Host-Authoritative Sync)

房主 (P1 Host) 以 60Hz 運算足球滾動摩擦、空氣阻力、門柱圓柱體碰撞、滑鏟衝量與進球越線判定，並透過不可靠通道（ordered: false, maxRetransmits: 0）以 30Hz 廣播快照；客端 (P2 Guest) 傳送操作向量並對座標進行線性插值（LERP），避免網路延遲造成的瞬移感。

3. 零外部素材依賴 (100% Procedural Assets)

球場草皮雙色條紋、白線禁區與經典黑白五邊形足球貼圖皆透過 Offscreen HTML5 Canvas 動態繪製生成；踢球低頻悶響、擊中門柱金屬聲與裁判哨音則由 Tone.js 即時合成，單一檔案即可離線或部署於任何靜態託管平台（如 GitHub Pages）。
